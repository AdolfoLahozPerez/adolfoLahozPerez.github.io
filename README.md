# CV Web — Adolfo Lahoz Pérez

Currículum Vitae en formato web, con diseño de dos columnas y opción de descarga en PDF.

## 📄 Descripción

Página estática que presenta el perfil profesional de **Adolfo Lahoz Pérez** (SysAdmin · Networking L2/L3 · Cybersecurity), incluyendo perfil profesional, competencias técnicas, experiencia laboral, formación y datos de contacto.

## 🗂️ Estructura del proyecto

```
├── index.html                       # Contenido y estructura del CV
├── estilos.css                      # Estilos visuales
├── foto_adolfo_lahoz_perez.jpg      # Foto de perfil (no incluida, debe añadirse)
└── CV Adolfo Lahoz Perez.pdf        # PDF descargable (no incluido, debe añadirse)
```

## 🎨 Características

- **Diseño de dos columnas**: columna izquierda con perfil, contacto, competencias e idiomas; columna derecha con cabecera, experiencia y formación.
- **Responsive**: en pantallas menores a 768px, las columnas se apilan y el orden cambia (cabecera → experiencia → datos de contacto).
- **Cabecera con foto**: nombre y subtítulo alineados junto a la foto de perfil en escritorio; apilados y centrados en móvil.
- **Botón de descarga**: enlace directo al CV en PDF.

## 🛠️ Tecnologías

- HTML5
- CSS3 (Flexbox, media queries)

## 📌 Notas para mantenimiento

- Para que la foto y el botón de descarga funcionen, ambos archivos (`foto_adolfo_lahoz_perez.jpg` y `CV Adolfo Lahoz Perez.pdf`) deben estar en la misma carpeta que `index.html`, con esos nombres exactos.
- El contenido del CV debe mantenerse sincronizado con la versión en PDF.
